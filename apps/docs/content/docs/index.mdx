# Agent Compat

`@jstn-sdk/agents` is a pure TypeScript SDK for cross-agent environment compatibility. Define your project once, generate native artifacts for each supported surface, and validate the result.

## Install

```bash
npm install @jstn-sdk/agents
```

The package is published on [npm](https://www.npmjs.com/package/@jstn-sdk/agents). Source, releases, and package assets live in the [GitHub repository](https://github.com/JustineDevs/agent-compat).
