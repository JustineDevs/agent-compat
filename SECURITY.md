# Security Policy

## Supported versions

Security fixes are applied to the latest published version of
`@jstn-sdk/agents` and the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/JustineDevs/agent-compat/security/advisories/new).

Include the affected version, adapter surface, reproduction steps, and
impact. Do not include secrets or private project data. We will acknowledge a
valid report and coordinate disclosure after a fix is available.

Do not report security vulnerabilities through public GitHub issues.
